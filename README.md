# ⚽ FIFA World Cup Analytics (1930–2026)

A comprehensive sports analytics project built using **Python, NumPy, Pandas, and Matplotlib** to analyze FIFA World Cup history, match statistics, team performance, attendance trends, and FIFA rankings.

---

## 📖 Project Overview

This project explores FIFA World Cup data from **1930 to 2026** and provides insights into:

- Most successful nations
- Goal-scoring trends
- Match-winning statistics
- Attendance analysis
- FIFA ranking changes
- Confederation distribution
- Stadium and referee statistics
- FIFA World Cup 2026 insights

The project demonstrates practical applications of **Data Analytics** using real-world sports datasets.

---

## 🛠️ Technologies Used

- Python 3
- NumPy
- Pandas
- Matplotlib
- Jupyter Notebook

## 📌 Key Insights

- Brazil is the most successful nation in FIFA World Cup history.
